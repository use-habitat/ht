# Code of Conduct

We want HT to be a welcoming, constructive project for contributors with
different backgrounds and levels of experience.

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Expected behavior includes empathy, respectful technical disagreement, clear
feedback, and care for user privacy. Harassment, discrimination, threats,
doxxing, and publishing another person's private information are unacceptable.

Report conduct concerns privately to `hello@use-habitat.com` with the subject
`HT conduct report`. Maintainers will limit disclosure to the people needed to
investigate and respond. Enforcement may include a warning, removal of content,
temporary restriction, or a permanent ban from project spaces.
