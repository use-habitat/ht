# Support

Use the [GitHub issue chooser](https://github.com/use-habitat/ht/issues/new/choose)
for reproducible bugs and scoped feature requests. Include your HT version,
operating system, provider, minimal reproduction, and sanitized logs.

Please do not post full agent transcripts, credentials, customer data, or
private repository paths. Replace them with synthetic values before sharing.

Community support is best-effort. Habitat Cloud may have separate support
terms. Security issues follow [SECURITY.md](SECURITY.md) and must not be filed
publicly.
