# Changelog

Notable user-facing changes are documented here. This project follows
[Semantic Versioning](https://semver.org/) while allowing pre-1.0 breaking
changes to ship in minor releases with migration guidance.

## [Unreleased]

### Added

- Public ingestion-v2 JSON Schema and canonical compatibility fixtures.
- Cross-platform, security, dependency, and supply-chain workflows.
- Contributor, support, security, governance, privacy, and roadmap documentation.

## [0.4.7] - 2026-08-24

### Added

- First standalone open-source HT release.
- Checksum-verified macOS and Linux binaries for Arm and x64.
- Local Codex and Claude Code capture, inspection, search, and optional Habitat
  Cloud synchronization.
