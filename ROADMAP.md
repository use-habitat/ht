# Roadmap

The roadmap describes direction, not a delivery commitment. Maintainers refine
scope in public issues before implementation.

## Now: dependable local capture

- Harden Codex and Claude Code adapters against provider format changes.
- Improve local search, diagnostics, recovery, and redaction transparency.
- Keep macOS and Linux installation and upgrades predictable.
- Maintain ingestion compatibility fixtures for hosted and self-hosted servers.

## Next: contributor-friendly extensibility

- Document a provider adapter interface and fixture test kit.
- Make redaction rules easier to inspect and extend.
- Add portable local export formats.
- Expand platform support based on tested community demand.

## Later: ecosystem integrations

- Community-provided exporters and ingestion adapters.
- Better lineage and handoff interoperability across agent providers.
- Stable protocol guarantees on the path to 1.0.

Use [feature requests](https://github.com/use-habitat/ht/issues/new?template=feature_request.yml)
to propose or discuss roadmap items.
