# Governance

HT uses a maintainer-led, open-development model. Current code owners are listed
in [`.github/CODEOWNERS`](.github/CODEOWNERS).

Maintainers set release scope, review pull requests, manage security response,
and make final decisions when discussion does not converge. Decisions should
optimize for user safety, local data integrity, compatibility, maintainability,
and the project's published direction.

Substantial changes begin with a GitHub issue or design document. Maintainers
seek relevant contributor input and record the decision in the issue, pull
request, or an architecture note. Routine changes use normal pull request
review.

Repeated, high-quality contributions can lead to expanded review or maintenance
responsibilities. Repository access does not grant access to hosted customer
data, production credentials, or the private Habitat Cloud codebase.
